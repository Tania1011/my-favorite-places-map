# 🗺️ My Favorite Places Map

A beginner-friendly Python project that uses **Object-Oriented Programming (OOP)** to create an interactive map of your favorite places using **Folium**.

---

## 🌟 Features

- Interactive map with markers for:
  - 🍽️ Restaurants  
  - 🌳 Parks  
  - 🏛️ Museums  
  - ☕ Cafes
- Popups show:
  - Food type for restaurants/cafes  
  - Entry fee for museums  
  - Wi-Fi availability for cafes  
- Different marker colors for each place type  
- Calculate distances between all places  
- Find the **closest pair of places** automatically  

---

## 📚 What You’ll Learn

- **Encapsulation** – Place class bundles data + methods  
- **Inheritance** – Restaurant, Park, Museum, Cafe inherit from Place  
- **Polymorphism** – `get_popup_text()` works differently for each type  
- **Abstraction** – `MyMap` hides map creation and marker logic
